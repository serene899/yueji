# 阅迹 · Yueji

LIFEOS 项目 05 —— 个人精神文化生活记录工具。

记录读过什么、看过什么，以及这些作品在不同时间带给自己的感受。
它不是书籍收藏夹，也不是社交平台：没有点赞、关注和排行榜，
只是一座可以长期积累的、只属于自己的文化生活数字档案。

**在线地址（iPhone Safari 打开，可添加到主屏幕）：**
https://serene899.github.io/yueji/

## 功能

- **首页**：文化生活概览（书/剧/电影/记录/收藏计数）、正在阅读、正在追剧（均带进度条与封面）、最近观影、最近记录
- **书架**：书籍、电视剧、电影、其他统一管理，类型/状态筛选与搜索；每部作品可加**封面**（从相册选图，压缩后只存本机；没图时自动生成一张按类型配色的「素封面」）
- **作品信息**：书名/作者/分类/年份/总页数；剧名/主创/类型/总集数；片名/导演/类型/片长；状态（想读/在读/读完、想看/在看/看完）、开始与完成日期、印象深刻标记
- **阅读记录**：日期、读到第几页、阅读时长、想法感受、收藏的句子；记到总页数自动标为读完
- **追剧记录**：日期、看到第几集、时长、感受、台词；看到最后一集自动标为看完
- **电影记录**：观看日期、感受、喜欢的台词或片段
- **作品详情**：封面大图、基本信息、进度、收藏句子墙、完整的阅读/观影历史（同作品多次记录并存，能看到感受随时间的变化）
- **年度回顾**：读完的书、追过的剧、看过的电影、记录条数、收藏句数、总时长、每月记录柱状图、印象深刻清单与年度小结
- **数据**：全部存本机浏览器（IndexedDB），无服务器；JSON 备份导出/导入恢复（封面包含在备份内；导入前完整校验，整库替换有二次确认；兼容 v1 旧备份）
- **LIFEOS 交换**：「我的」页可生成发往人生K线图的交换文件（只送读书时长与文化活动事实，不送感受原文）

版本沿革：v0.1.0 首次实现（书+电影）→ v0.2.0 LIFEOS 交换导出 → v0.3.0 电视剧、其他类型与封面 → v0.4.0 逻辑重构（状态联动按记录重算、进度不被完成状态篡改、年度活动/完成双口径、其他细分类）与全局 UI 升级（五栏导航、记录页、书架网格视图）。

## 技术

React 18 + TypeScript + Vite + Dexie（IndexedDB）+ Tailwind CSS + vite-plugin-pwa。
与生息、钱在哪同一套 LIFEOS 本地优先标准：相对路径构建、GitHub Pages 子路径部署、数据只存本地。

```bash
npm run dev        # 本地开发（127.0.0.1:5305）
npm run build      # 类型检查 + 构建到 dist/
npm test           # 单元测试（vitest）
npm run test:e2e   # 端到端测试（Playwright，iPhone 13 视口）
```
