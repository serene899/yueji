# 阅迹 · 项目现状报告 v0.5.2（小修 · TMDB 片长自动补 + 占位数字去误会）

日期：2026-11-25 · 负责人：Atlas · 触发：所有者填入 TMDB 密钥后实测《功夫》——导演/主演/类型/年份全部自动补上，但他问「时长不确定有没有弄上去」

## 一、问题诊断

- **片长确实没补上**：TMDB 搜索结果不含片长，片长在详情接口里（runtime），v0.5.1 没拉详情。截图里片长栏显示的「143 分 16 秒」其实是输入框的**灰色占位示例数字**（v0.4.3 时随手写的 143/16），与《八仙》的真实片长撞车，极易误认为已填入——所有者的怀疑是对的。

## 二、修复

- 选中 TMDB 条目后，按 id 再拉一次详情：电影补**片长**（runtime，整分钟；TMDB 不给秒，秒栏留空由他按需补），电视剧顺带补**总集数**（number_of_episodes）。仍只填空栏。
- 时长双输入（片长与记录时长共用组件）的占位数字由 143/16 改为 0/0，杜绝「占位被当成已填」的误会。

## 三、验证

- tsc 0 错误；单测 58/58（新增详情映射 1 例）；e2e 8/8（TMDB 用例加断言：详情 runtime 99 → 片长分钟自动填 99）。
- 线上核验：部署后站点与 JS 资源 200，包内版本号 v0.5.2。

## 四、实测确认（所有者真机）

TMDB 全链已由所有者在真机跑通：《功夫》导演周星驰、主演周星驰/元秋/元华/林子聪/梁小龙/黄圣依…、类型动作、年份 2004 均自动补齐无误。本版后片长也会自动补（《功夫》应为 99 分）。
