## 本版完成（v0.1.0）

- 首页：概览计数、正在阅读（进度条）、最近观影、最近记录
- 书架：书籍/电影统一列表，类型与状态筛选、搜索；作品增删改（书名/作者/分类/年份/总页数；片名/导演/类型/片长；状态、开始/完成日期、印象深刻）
- 阅读记录：日期、读到页码、时长、感受、收藏句子；小联动——首条记录自动「在读」、记到总页数自动「读完」、电影首条记录自动「看完」
- 电影记录：观看日期、感受、台词/片段收藏
- 作品详情：基本信息、进度、收藏句子墙、完整历史（同作品多次记录并存）
- 年度回顾：读完书数、看过电影数、记录/活跃天数/收藏/时长、每月柱状、印象深刻清单、年度小结句
- 数据：IndexedDB 本地存储；JSON 备份导出/导入（导入前全量校验、整库替换二次确认）；PWA 可添加到主屏幕、离线可用
- 体验：暖纸+朱砂的书卷气设计、宋体标题、深色模式随系统、iPhone 安全区与大字号防缩放
