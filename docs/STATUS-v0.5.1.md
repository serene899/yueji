# 阅迹 · 项目现状报告 v0.5.1（增强 · TMDB 海报源接入）

日期：2026-11-25 · 负责人：Atlas · 触发：v0.5.0 上线后，所有者当场拍板「带我注册 TMDB 密钥，把真人电影海报命中率也拉满」

## 一、本版做了什么（代码侧已全部就绪，只差所有者填入密钥）

- **「我的」页新增「联网海报源（TMDB）」区**：密钥输入框 + 保存/清除 + 注册入口链接。密钥**只存本机 localStorage**——不进数据库、不进备份、不进 LIFEOS 交换文件，清除一键可删。
- **搜索优先级**：填了密钥后，电影/电视剧的「联网找封面」优先走 TMDB（语言 zh-CN，海报 + 年份 + 类型）；TMDB 没结果、或密钥不对（401 会明示并自动回落），自动回落 v0.5.0 的 Bangumi + Wikidata 组合，行为不退化。
- **选中 TMDB 海报后补全**：导演（credits 里 job=Director）、主演（按出场序前 6 位）、类型（TMDB 类型映射为中文且与阅迹现有分类对得上时才填）——仍遵守「只填空栏、不覆盖已写内容」。
- 书的 Open Library 路径不变；没填密钥时界面会提示可去「我的」填 TMDB 密钥。

## 二、密钥注册（所有者本人操作，Atlas 逐步带）

1. themoviedb.org 注册账号（用户名 + 邮箱 + 密码）→ 点邮箱里的验证链接激活。
2. 登录 → 头像菜单 Settings → API → 创建 API Key (v3)，申请表填：Application Name = Yueji；URL = https://serene899.github.io/yueji/；Summary = 个人用途说明（Atlas 已备好英文文案，届时照抄）。
3. 把得到的 API Key 粘贴进阅迹「我的」→「联网海报源（TMDB）」→ 保存。

## 三、验证

- tsc 0 错误；单测 **57/57**（新增 TMDB 搜索结果与演职员映射 2 例）；e2e **8/8**（新增：预置密钥 → TMDB 候选出现 → 选中后导演/主演/年份/类型全部补上）。
- 线上核验：部署后站点与 JS 资源 200，包内版本号 v0.5.1。

## 四、未动
