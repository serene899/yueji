# 阅迹 · iPhone 使用与数据说明

## 打开与添加到主屏幕

1. 用 iPhone Safari 打开 https://serene899.github.io/yueji/
2. 点底部分享按钮 →「添加到主屏幕」→ 添加。桌面会出现「阅迹」图标，之后点图标就是全屏打开，跟普通 App 一样。

## 数据存在哪里

- 全部数据（作品、记录、感受、摘抄）只存在**这台手机这个浏览器**的本地数据库（IndexedDB）里。
- 没有服务器、没有账号、不上传任何地方。别人（包括开发者）看不到你的记录。
- 刷新、关掉页面、重启手机，数据都还在。

## 备份与恢复（重要）

Safari 有时会清理长期不打开的网站数据，换手机或清浏览器前**一定要先导出备份**：

- **导出**：「我的」→「导出备份（JSON）」，把生成的 `yueji-backup-日期.json` 存到文件 App 或 iCloud 里。建议每个月导一次。
- **恢复**：在新环境打开阅迹 →「我的」→「从备份文件恢复」→ 选备份文件 → 确认。恢复会**替换**当前全部数据，导入前会先完整校验文件，校验不过不会动原有数据。

## 已知注意事项

- 主屏幕图标：图标文件经当前 GitHub 推送通道会损坏（LIFEOS 三个 App 的共同已知问题），添加到主屏幕后图标可能显示为默认样式，不影响使用。
- 离线可用：打开过一次之后，Service Worker 会缓存应用本体，断网也能记。
