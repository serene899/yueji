# 阅迹 · 项目现状报告 v0.4.1（小修）

日期：2026-11-21 · 负责人：Atlas · 触发：所有者真机录屏反馈两点

## 一、修复：切到书架时悬浮「+」按钮上下摆动

- **现象**：点底栏切到书架的瞬间，红色 + 按钮先出现在页面中部（压在第一张卡上），随即掉回右下角；来回切换反复出现。
- **根因**：v0.4.0 给页面切换加的 `.view-enter` 动画用了 `transform: translateY`。带 transform 的祖先会成为 `position: fixed` 元素的包含块，动画期间 + 按钮的 fixed 定位相对内容容器计算（被拽到页面中部），动画结束 transform 消失后才弹回视口定位。
- **修法（与钱在哪 v0.6.1 同一处方）**：页面切换动画只动 opacity、不动 transform。已把钱在哪的踩坑注释同步写进阅迹 index.css，避免以后再犯。
- **验证**：切换后 120ms（动画进行中）截图，+ 按钮已在右下角最终位置，不再中途漂移。

## 二、新增：底栏液态玻璃滑动指示（模仿生息）

- 机制整体沿用生息 v0.4.4（其机制又源自钱在哪）：选中指示块是一块 3D 液态玻璃——多层渐变体积 + 顶部镜面 gloss + 底部折射 caustic + backdrop 再折射；**可手指拖动跟随**，拖动时按距离拉伸（上限 +20%）、按速度倾斜（±7°），松手以弹簧曲线 `cubic-bezier(0.34, 1.35, 0.64, 1)` 回弹并就近吸附切换页面；拖动后的尾随 click 会被吞掉，不会误触。
- 阅迹化调整：折射染色由生息的系统蓝换成阅迹朱砂暖色（浅色 `rgb(168 62 33)`、深色 `rgb(224 122 95)`），与暖纸底统一；深色模式令牌一并适配。
- 附带一致性修正：打开作品详情时，底栏保持所在 Tab 的高亮与指示块位置（此前详情页五个 Tab 全灰、与新指示块矛盾）。
