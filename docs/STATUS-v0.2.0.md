# 阅迹 · 现状报告 v0.2.0（2026-11-19）

本版只做一件事：新增 LIFEOS 交换导出，落实所有者定下的人生K线图数据汇入模型（阅迹负责「学习」「精神生活」两维的数据来源）。

- 「我的」页新增「发到人生K线图」区：生成 lifeos-exchange v0.1.2 交换文件（本机生成、用户自己保存，阅迹不联网发送）。
- 内容只有事实：x-reading-minutes（按日汇总的读书时长，只计书籍类记录）、x-culture-activity（按日文化活动：条数 + 写了感受/摘句/当天读完看完三个布尔标志）。
- 红线：感受原文、摘句原文绝不进交换文件（有单测锁定）；manifest 明示 scoringPolicy = facts-never-produce-scores，阅迹只送事实、不送分，分数由人生K线图按其试行锚点计算。
- 每条记录带 contentHash、文件带 SHA-256 校验和（JCS 规范化），与钱在哪/生息同口径。
- 测试：单测 20/20（新增 2 例）、e2e 2/2、tsc 0、构建成功。真机 Safari 验收待所有者。
- 未做：音乐记录（仍待后续）、与人生K线图的直读自动同步（先走文件接力，直读方案待真机验证存储隔离后再议）。
