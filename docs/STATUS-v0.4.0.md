# 阅迹 · 项目现状报告 v0.4.0

日期：2026-11-21 · 负责人：Atlas · 依据：《阅迹 v0.4.0 全面升级任务书》（所有者经 GPT 评审后下达）

## 一、任务书核对结论（先核对、再动手）

- **P0「首页不显示电视剧」属实，但根因与任务书猜测略有出入**：v0.3.0 的最近观影查询本身包含电视剧记录；真正的盲区是**只有作品、没有记录**的情况——用户把看完的剧直接标「看完」而不补记录时，首页永远不出现。本版按「记录 + 完成日期」双来源修复，并加了专门的回归测试（只加作品标看完、零记录）。
- 其余 P1/P2 与自查 Q1–Q10 对应关系：Q1→状态联动重做，Q2/Q3→年度双口径，Q4→电影保留三档状态（任务书口径），Q5→概览拆作品数/活动数，Q6→记录表单折叠非必填项（只记进度更快），Q7→电影时长片长兜底，Q8→重复提醒，Q9→维持现状（任务书未要求改，仍只送事实），Q10→细分类落地。

## 二、逻辑修复与功能调整（已完成）

1. **状态联动重做（db.syncWorkStatus）**：记录增/删/改后按全部记录重新推导状态。删掉达标记录 → 状态退回进行中、完成日期清除；删光记录 → 回计划中。进度永远由记录现算，**完成状态不再把进度篡改成 100%**（标了读完但记录只到 60%，就显示 60%，详情页有文字说明）。
2. **手动优先**：编辑已有作品时手动改状态 → 状态锁定（statusLocked），之后记记录只更新进度、不改状态，详情页显示「状态手动管理中」，表单里可「恢复自动」。新建作品时选的状态只是起点，不锁定。暂停/搁置永不被联动改动。
3. **状态补齐**：书（想读/在读/读完/暂停/弃读）、剧（想看/在看/看完/暂停/弃剧）、电影（想看/观看中/看完）、其他（五档，中性文案）。从已完成改回未完成时，完成日期自动清除。
4. **年度回顾双口径**：活动按记录日期（阅读/观看/其他分开统计，其他按细分类汇总）；完成按完成日期且状态须为已完成——跨年剧活动可多年出现，完成只计一次；「改回在读但残留完成日期」不再误算。
5. **其他细分类**：音乐/播客/纪录片/综艺/游戏/演出/展览/其他，可选字段，书架可按细分类筛选，年度回顾有细分类汇总。
6. **重复作品提醒**：同类型同名保存时先弹出提醒，用户确认后仍可保存（同名不同作品的正当情况）。
7. **时长口径**：电影记录没填分钟时按片长计入时长统计（详情累计、年度总时长）。
8. **备份时间提示**：「我的」页记录上次导出时间，超 30 天或从未备份会给出提醒。

## 三、数据结构

- Dexie 仍 v1，零迁移：Work 新增可选字段 `subcategory`、`statusLocked`；WorkStatus 枚举扩为 5 值（旧值不变）。
- 备份仍为 schemaVersion 2（新字段随作品对象走），校验放行新状态与新字段；**v1、v2 旧备份继续可恢复**（单测锁定）。

## 四、UI 与移动端（已完成）

- **设计系统**：类型识别色定版（书朱砂暖 / 剧蓝紫 / 电影靛青冷 / 其他灰褐），只用于封面、进度条、标签等点缀；玻璃材质只给底栏与弹层；卡片保持实色+柔和阴影+发丝边框；系统字体栈，宋体只用于品牌与标题；新增页面切换淡入、卡片按压、进度条生长、封面淡入动画，并尊重「减少动态效果」。
- **底部导航五栏**：首页 / 书架 / 记录（新增）/ 回顾 / 我的，半透明毛玻璃。
- **首页**：日期+问候语开头；概览改为「收藏作品 / 已完成 / 阅读记录 / 观看记录」四格（分清作品与活动）；「正在阅读」「正在追剧」合并为「正在进行」；「最近观影」改名「最近观看」并修复 P0。
- **书架**：新增**网格视图**（封面优先、三列、状态小签、迷你进度条），与列表一键切换并记住选择；「其他」筛选下出现细分类筛选行；状态筛选补齐五档。
- **记录页（新增）**：全部记录按月倒序成册，点按直达作品。
- **作品详情**：封面放大；信息行补「N 次记录」「状态手动管理中」；进度卡在无页码数据时给出占位说明；完成但进度不满时有口径说明。
- **记录表单**：感受/句子默认折叠（只记进度两步完成），编辑旧记录时自动展开；日期默认今天、保存按钮常驻。
- **年度回顾**：大年份标题+编辑感排版；完成与活动两块分开陈列；完成清单与印象深刻都带封面。
- **我的**：备份时间提示（见上）。
