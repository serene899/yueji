# 阅迹 · 项目现状报告 v0.4.2（小修 · 字体）

日期：2026-11-21 · 负责人：Atlas · 触发：所有者真机截图圈注（首页概览数字、年度 2026 与统计数字、总时长、月度标签）

## 一、问题诊断

1. **数字字形又粗又怪**：宋体栈把中文宋体（Noto Serif SC / Songti SC）排在 Georgia 前面，拉丁数字先命中中文宋体，被其粗重的老式数字字形渲染——概览的 2/1/2/0、大号 2026、统计数字全中招。
2. **数据数字与标签字体混杂**：统计数字用宋体、正文标签用黑体，同一卡片里两种字体打架；「1 小时 27 分」数字宋体+汉字黑体感明显，且字号偏大易挤。
3. **月度标签折行**：「10月/11月/12月」在窄列里折成两行（数字一行、「月」一行）。

## 二、修复（确立阅迹字体规则）

1. **宋体栈重排**：Georgia 提到最前——拉丁字母与数字走 Georgia（优雅的老式数字），汉字落 Songti。年份大字「2026」保留宋体展示位，数字即为 Georgia 字形。
2. **数据数字一律黑体**：首页概览、年度完成/活动两组统计、详情页进度百分比，全部改为系统黑体加粗 + tabular-nums（等宽数字不跳动）。「总时长」字号微降并禁止折行，单行呈现。
3. **月度标签**：字号 9.5px + 不折行，「10月」单行显示。
4. **保留宋体之处**（有意为之）：品牌字、作品名、章节标题、收藏句子——阅迹的纸面档案性格所在，汉字宋体的观感本身没有问题。

> 阅迹字体规则（自本版起）：**数据用黑体，标题与作品名用宋体，宋体里的数字走 Georgia。**
