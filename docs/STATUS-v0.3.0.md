# 阅迹 · 项目现状报告 v0.3.0

日期：2026-11-21 · 负责人：Atlas

## 本版缘起（所有者 2026-11-21 提出）

1. 刚看完一部电视剧，想在阅迹里记电视剧，以后还想记「其他各种各样的东西」；
2. 他已经在阅迹里加了第一本书，反馈列表看起来单调，想给书加封面，电影、电视剧也要能记封面。

## 本版完成（v0.3.0）

- **新类型：电视剧** 📺 —— 剧名、主创（导演/主演）、类型、播出年份、**总集数**；记录按「看到第几集」推进度（松绿色进度条），看到最后一集自动标「看完」，第一条记录自动从「想看」变「在看」。首页新增「正在追剧」区，年度回顾新增「部追过的剧 / 这一年追过的剧」。
- **新类型：其他** ✦ —— 音乐、播客、演出、展览、游戏等先归到这里兜底记录（名称、创作者、分类、状态、感受、台词/片段），不为每个品类单独造结构；用得多再拆专门类型。
- **封面** —— 添加/编辑作品时可从相册选封面图：等比压缩到最长边 800px 转 JPEG（几十 KB），只存本机 IndexedDB；书架、首页、详情页都展示。**没有封面时自动生成「素封面」**：按类型配色（书朱砂、剧松绿、电影靛青、其他褐）+ 宋体标题 + 作者，列表不再是一片文字。
- **备份升级到 v2**：封面以 base64 形式进备份文件，恢复后封面一起回来；导入端兼容 v1 旧备份。单测锁定字节往返一致与坏数据拒绝。
- 数据结构：Dexie 仍为 v1（新字段全是可选加键，旧数据零迁移）；已有的那本书不受影响，上线后直接编辑它加封面即可。

## 与 LIFEOS 交换的关系（透明说明）

- 交换协议格式与字段**未动**（仍 lifeos-exchange v0.1.2、appVersion 字段更新为 0.3.0）。
- 口径沿用 v0.2.0 的既有定义：`x-reading-minutes` 仍**只计书籍**记录的时长（追剧时长不会污染「学习」维）；`x-culture-activity` 本就是「按日文化活动记录条数」，电视剧/其他类型的记录会和电影一样被计入——这与「精神生活」维的定义一致。若所有者希望剧集不计入，再单独关。
